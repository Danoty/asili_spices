## Publish on GitHub Pages
1. Create a new public repository, e.g. `asili-spices`.
2. Upload all files and folders from this website package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public website URL.

## Publish on Netlify
Drag the `asili-spices-website` folder into Netlify Drop or connect the GitHub repository. No build command is required.

## Publish on cPanel / normal hosting
Upload the contents of the folder into `public_html` (or the domain document root). Ensure `index.html` is directly inside that directory.
