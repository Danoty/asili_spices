# Asili Spices Website

Publication-ready static website for Asili Spices.

## 1. Add official contact details
Edit `assets/js/config.js` and fill in:
- phoneDisplay
- phoneInternational (digits only, e.g. 2547XXXXXXXX)
- email
- location
- Instagram / Facebook / TikTok links

## 2. Publish on GitHub Pages
1. Create a new public GitHub repository, for example `asili-spices`.
2. Upload every file and folder from this package to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will generate the live website address.

## 3. Custom domain (optional)
After buying a domain, add it in GitHub Pages under **Custom domain** and update DNS with your registrar.

The current spice categories are presented as a broad brand range. Before publication, confirm which products Asili Spices actually stocks and remove any item that does not apply.
